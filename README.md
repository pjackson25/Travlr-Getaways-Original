# Travlr Getaways – Original Artifact

## CS 499 Computer Science Capstone

This repository contains the original version of the **Travlr Getaways** full-stack web application that I developed during **CS 465: Full Stack Development** at Southern New Hampshire University.

This version serves as the **baseline artifact** for my CS 499 Computer Science Capstone ePortfolio. The application was later enhanced during CS 499 to demonstrate growth and proficiency in three areas of computer science:

- Software Design and Engineering
- Algorithms and Data Structures
- Databases

## Original Application

Travlr Getaways is a full-stack travel application developed using the MEAN stack. The project includes a customer-facing website, a REST API, MongoDB database integration, and an Angular administrative single-page application.

Technologies used include:

- MongoDB
- Express
- Angular
- Node.js
- JavaScript and TypeScript
- Mongoose
- REST APIs
- JSON Web Token (JWT) authentication

## Repository Structure

The original application source code is located in the `travlr` directory.

This repository represents the application **before the CS 499 enhancements** and is preserved to demonstrate the progression from the original artifact to the enhanced version presented in my ePortfolio.
